# Interceptly MCP Example

This example demonstrates how to run or interact with `interceptly_mcp`.

## Running the CLI

Install globally:

```bash
dart pub global activate interceptly_mcp
```

Run against a local Flutter app:

```bash
interceptly_mcp --uri ws://127.0.0.1:54321/ws
```

Or run directly from source:

```bash
dart run bin/interceptly_mcp.dart --uri ws://127.0.0.1:54321/ws
```

## Running the Dart Example

```bash
dart run example/main.dart
```
